# Voice-Controlled Pan-Tilt Robot Head — Journal Website

A responsive, static journal-style website made with plain HTML, CSS and JavaScript. It is suitable for editing in Visual Studio Code and does not require React, Node.js, a database or a build step.

## Files
- `index.html` — complete article content and page structure
- `style.css` — layout, typography, responsive design and print styling
- `script.js` — mobile navigation and back-to-top button

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `voice_controlled_robot_journal` folder in VS Code.
3. Open `index.html`.
4. Install the **Live Server** extension if you do not already have it.
5. Right-click `index.html` and select **Open with Live Server**.

You can also double-click `index.html` to open it directly in a browser.

## Before submitting or publishing
- Replace the Figure 1 placeholder with your actual system block diagram.
- Replace the Figure 2 placeholder with a genuine photograph of the assembled robot.
- The source report leaves the measured heap value after the 4-second buffer, the observed functional-test results and the network timing table unfilled. They are marked as “Not recorded” here. Add actual measurements only after testing; do not invent results.
- Confirm the authors' names, register numbers, course details and references with your instructor.
- If this is being submitted as a journal publication, ask your instructor whether a specific journal template, citation style, DOI, journal name or publication metadata is required. This site is a web presentation of the report; it does not itself publish the work to an academic journal.

## Customization
Edit the article text directly in `index.html`. Change colors and spacing in the `:root` section at the top of `style.css`.
